What I've been building.

Alongside the writing, most of my time goes into actual systems for Queensland croquet — some live now, some running quietly before anyone's told, some still being built. This is the honest list, updated as things change.

Live now

Come & Try Croquet

Live

The prospect funnel that turns a curious click into someone's first game at a real club — club-day listings, sign-up, and the follow-through that gets them there.

MyCroquet — Decisions module

Live

Committee motions and votes, properly recorded, so a decision doesn't just live in someone's memory of a meeting.

CAQ grants system

Live

Watches for grant opportunities, drafts the case, and puts a real decision in front of Wade before anything is applied for — nothing reaches a club without a human saying yes.

HOOPLA! news site

Live

Queensland croquet's own news site — club stories, results, and the weekly newsletter, in one place instead of scattered across Facebook.

CAQ policy document wiki

Live

One searchable home for CAQ's governance documents and policies, instead of versions scattered across email threads and old PDFs.

Built and running, not yet announced

MyCroquet — Club Treasurer

Dark-shipped

Cash-accounting bookkeeping for club committees — one place to see where the money is, instead of a spreadsheet only the treasurer understands.

MyCroquet — Coaching & Refereeing credentials

Dark-shipped

A proper register of who's qualified to coach or referee, replacing a manual RevSport process — built with input from CAQ's coaching coordinator.

MyCroquet — Events module

Dark-shipped

Club and tournament event listings with entries and payment, waiting on a final review pass before it goes public.

MyCroquet — Publisher module

Dark-shipped

Lets a club run its own site content without touching code — verified on staging, waiting on a go-live decision.

Still being built

Club website directory

In progress

Every Queensland club gets a free site and domain through MyCroquet — no club left without a decent web presence for the cost of asking.
